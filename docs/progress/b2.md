   new snapshots `main_{ember,paper}_120x32`. README and docs/manual-test.md updated.
5. **Grapheme-aware truncation (confirmed).** `unicode-segmentation` added to ks-ui. `truncate_end`,
   `truncate_start`, `truncate_middle` iterate grapheme clusters measured with `UnicodeWidthStr::width`;
   `truncate_middle` re-checks the assembled width. The palette label already goes through `truncate_end`.
   `search.rs` `path_spans`/`input_spans`/`hit_spans` now work on grapheme clusters (`clusters()`), widths measured
   per cluster (`char_width` removed); a cluster is highlighted when any of its chars is in the match indices, so ZWJ
   sequences are no longer over-counted. Test `path_spans_measure_zwj_sequences_as_one_cluster_and_highlight_it`. Tests: extended `middle_truncation_never_exceeds_the_budget` (VS16, keycap, ZWJ),
   new `end_and_start_truncation_respect_grapheme_clusters`.
6. **Config `[files] show_hidden/show_ignored` (confirmed).** `AppState::new` seeds `search.finder_hidden` /
   `finder_gitignore`; `ConfigReloaded` re-seeds only a value whose config value changed (session toggles survive
   unrelated reloads); content search uses `respect_gitignore = !config.files.show_ignored`
   (`show_hidden` still follows the pane toggle). Tests in `ks-core/src/search/tests.rs`.
7. **Find-file access-denied count (confirmed).** `FinderSnapshot.denied` / `FinderState.denied`, filled in the
   ks-app finder worker from `walk_summary()`; footer shows `N denied` only when N > 0.
