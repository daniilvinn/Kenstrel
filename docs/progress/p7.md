# P7: tabs, bookmarks, frecency, shell integration

Branch `phase/p7` (base bf87255), not committed. Gates (`cargo fmt --all`, `cargo clippy
--workspace --all-targets -- -D warnings`, `cargo test --workspace`) are clean; the workspace has 372
tests, of which about 130 are new.

## Done

- **Tabs** (`ks-core/src/tabs.rs`). `t` new tab next to the current one (same directory, same sort
  and hidden setting, cursor carried over; opens on This PC when the current tab is there), `1`..`9`
  switch, `ctrl-w` close (the right neighbour takes over, closing the last one shows its left
  neighbour). Closing the only tab is a no-op with the status hint "This is the last tab (q
  quits)". At most 9 tabs.
  - Design: the active tab's navigation state stays in the existing `AppState` fields (`cwd`,
    `view`, `history`, `cursor_memory`, `nav`, `drives`, `git`, the five gen counters), so **no
    existing code changed to become tab-aware** (no `active()` accessor was needed). The other
    tabs are parked in `AppState::tabs` as `TabSlot`s that are swapped with those fields
    (`mem::swap`) on a switch.
  - Routing of background results: every tab has generation counters in its own space
    (`GenCounter::in_space(tab)`, tickets are `space << 32 | n`), so a listing, watch, git or
    child-count result belonging to a parked tab can never equal a current ticket of the active
    tab and is dropped by the existing generation checks. Leaving a tab also bumps all of its
    counters, drops its pending navigation (a pending history move puts its entry back) and
    leaves visual mode. Returning to a tab re-lists it (refresh keeps the cursor on its entry by
    name and prunes marks of vanished names), restarts the watcher and re-runs `git status`.
  - Tab strip `1 ▏2 ▏3` at the right end of the header, after the git summary, active tab in bold
    accent, others dim; hidden with a single tab; `|` with the ascii icon set.
- **Bookmarks** (`ks-core/src/bookmarks.rs`, `aids.rs`). `m<char>` sets, `'<char>` jumps (unknown
  key: warning "No bookmark x"; vanished directory: the normal "Cannot open ..." error, the view
  is left alone). `M` or the palette entry "List bookmarks" opens the list overlay (`j/k`, `enter`
  jumps, `d`/`delete` deletes, `esc`/`q` closes). New actions `bookmark.list` and
  `bookmark.delete` (the latter for the overlay); `bookmark.set`/`bookmark.jump` invoked without
  their character (palette) wait for it by pushing the `m`/`'` prefix as pending key.
  Persisted in `%LOCALAPPDATA%\kestrel\state\bookmarks.toml` (`[bookmarks]` table, key = the
  character), written on every change.
- **Frecency** (`frecency.rs`, `aids.rs`). zoxide model: rank +1 per visit, score = rank x bucket
  (<1 h x4, <1 d x2, <1 w x0.5, else x0.25); when the ranks sum above 10 000 all ranks are x0.9 and
  entries below 1 are dropped; at most 5 000 entries. Updated on every committed directory change
  (including the start directory, history moves and climbs). Windows paths are keyed
  case-insensitively with `/`. Vanished directories are pruned lazily: a failed navigation
  with NotFound/NotADirectory removes the entry. `z` opens the jump overlay (rounded border, title
  "Jump to directory", `›` input, `shown / total` counter, rows with matches in the `match`
  colour + bold); ranking = frecency score x nucleo-matcher fuzzy score (smart case, path
  matching config) on the `~`-abbreviated path; the current directory is left out; empty query =
  pure frecency order; `enter` jumps, `up/down/ctrl-n/ctrl-p/ctrl-j/ctrl-k` move, `ctrl-u`/`ctrl-w`
  edit, any other printable key is query text. Persisted in `frecency.toml` (`[[entries]]` path /
  rank / last).
- **Persistence** (`ks-app/src/persist.rs`). Atomic writes (temp file in the same directory +
  rename), all through one writer thread so writes are applied in order and never on the UI
  thread. Loading runs in `spawn_blocking` after `Msg::Start` (`Effect::LoadNavData` ->
  `Msg::NavDataLoaded`) and is merged with what happened meanwhile. Frecency writes are debounced
  (first unsaved visit arms a 5 s `TimerKind::StateSave`; later visits join it) and flushed on exit
  by the event loop (`pending_writes`, then waits up to 2 s for the writer). Damaged file: the file
  is renamed to `<name>.bad`, the app starts with empty data and shows a status warning.
  `AppPaths::state_dir()` added; paths are injectable (`EffectRunner::set_state_dir`).
- **Shell integration.** `ks --print-shell-init <powershell|pwsh|bash|zsh>` prints the function
  `k`. PowerShell version uses `New-TemporaryFile`, `ks --cwd-file`, `Get-Content -LiteralPath
  -Encoding UTF8 -Raw`, ignores an empty or vanished target, and removes the temporary file in a
  `finally`. The bash/zsh version converts with `cygpath -u` when present (Git Bash). README has a
  new section (profile line, the PowerShell 5.1 encoding reason, Windows Terminal profile
  command line). The existing `--cwd-file` writer and exit-path selection (only `Q` writes) are
  unchanged and still covered by `startup::tests`.
- **History**: not persisted separately. Decision: frecency already is the persistent record of
  visited directories; per-tab back/forward history stays session-local (it is cheap to add
  later, but a second file would mostly duplicate frecency).
- Palette: all actions are in `Action` (`tab.new`, `tab.goto`, `tab.close`, `bookmark.set`,
  `bookmark.jump`, `bookmark.list`, `bookmark.delete`, `frecency.jump`), so they appear once the
  palette lands. `tab.goto` needs a number argument, so the palette should offer it per tab or
  as "Switch to tab N".

## Deviations

1. **Only the active tab is watched** (PLAN 7: "watch the current dir and the dirs visible in
   tabs"). A parked tab is re-listed when activated (cursor kept by name), which shows the user
   the same thing without a watcher per tab, and the existing single-slot watcher effect needed
   no change. If background tab badges are wanted later, `WatchDir` must become a set.
2. **`M` for the bookmark list**, no `g b`: `g b` grew the `g` which-key group by one entry and
   cut off its last item in the 160x48 snapshot owned by P1/P5.
3. **No `active()`/`active_mut()` accessors** and no `TabState` wrapper: swapping the per-tab
   fields in and out of `AppState` achieves the same with zero changes in `nav.rs`/`list.rs`/
   `render.rs` (see Design). `AppState` gained two fields (`tabs`, `aids`).
4. **Jump overlay has no live preview pane** on the right at >= 100 columns (PLAN 4.3): the
   preview engine is P2; add it there.
5. **Frecency matches the displayed text** (`~/code/kestrel`), not the absolute path, so highlight
   positions line up with what is drawn. Typing `users` therefore does not hit `C:/Users/me/...`
   when home is shown as `~`.
6. **The `m`/`'` prefix for palette use** is pushed as a pending key; if the user unbinds the
   prefix the action falls back to a status hint ("Press m followed by a character").
7. New tab starts with an empty list until the first chunk arrives (no view cloning), so there
   is a one-frame empty list on `t`.
8. `Q` writes the directory of the **active** tab.

## VERIFY results

- **Windows PowerShell 5.1 and `Get-Content`**: a UTF-8 (no BOM) file containing
  `C:\Zażółć é` read with plain `Get-Content -Raw` does not equal the original; with `-Encoding
  UTF8` it does. Confirmed on this machine (5.1.26100). The shell function therefore always passes
  `-Encoding UTF8`.
- **End-to-end `Q` + function**: `tests/shell_init.rs` runs the exact text printed by the real
  `ks.exe --print-shell-init powershell` in a real `powershell.exe` (5.1) with a stand-in `ks.ps1`
  that writes the cwd file like `ks --cwd-file` (UTF-8 without BOM, no newline): the shell ends in a
  directory with a space and non-ASCII characters; with an empty file (plain `q`) or a vanished
  directory it stays; no temp file is left. The same test runs against `pwsh.exe` when installed
  (not installed here, so skipped). The real TUI cannot run in tests.
- **`ks --print-shell-init powershell | Out-String | Invoke-Expression`** defines the function in
  5.1 (checked).
- **Atomic replace**: `std::fs::rename` over an existing file works on Windows (tests write twice
  and a failing rename leaves the old file and no `.tmp`).
- **nucleo-matcher 0.3.1** `Pattern::indices` positions are char offsets into the haystack
  (used directly for highlighting; test with `~/projects/...` rows).

## Measurements

Release build, `z` with a full database (5 000 entries, paths of 3 to 6 segments), whole `update`
including the ranking: open overlay 2.3 ms; typing 2.7 ms per keystroke (debug build: 9.9 ms and
23 ms). Run: `cargo test -p ks-core --release -- --ignored --nocapture z_ranking_time`. The ranking
runs on the UI thread; it stays inside the 16 ms frame budget in release at the entry cap. If the
cap is ever raised, move it to a background job with a generation id.

## Review follow-up

Fixed:
- State-file safety: nothing is written until the start-up load has been merged (`NavAids::loaded`;
  frecency stays dirty and is re-armed by `on_loaded`, bookmark edits are written right after the
  merge, bookmarks deleted before the load are tombstoned). A file that exists but cannot be read
  (`LoadedNavData::unreadable`) is never written this session; the problem is shown in the status
  line. `atomic_write` retries the rename a few times (Windows sharing violations).
- Opening a tab no longer counts as a frecency visit.
- `tab.goto` without a number now says "Press 1-9 to pick a tab".
- `tabs.rs` has an exhaustive destructure of `AppState` (`classify_state_fields`): a field added by
  another track breaks the build until it is classified as per-tab (add to `TabSlot::swap_with`)
  or shared.
- Tests: load ordering/unreadable/tombstones, ctrl-w in the `z` overlay, switching mid-navigation,
  tab-open visit accounting, unreadable file; snapshots for tab strip + git summary and for the
  pending `m` / `'` prefix (80x24, 160x48, both themes).

Deferred / open (integrator notes):
- Parked tabs are not watched (PLAN 7 asks for all tabs). Needs a multi-path `WatchDir` in the
  effect protocol; the re-list on switch hides it except for a brief stale view, and a vanished
  directory keeps its old entries plus a "Cannot open" status.
- `z` overlay has no live preview at width >= 100 (PLAN 4.3): wire it to the P2 preview engine.
- The bookmark list stays on `M` (not in PLAN 5; `g b` collided with another track's which-key
  snapshot). Reachable by palette as `bookmark.list`; the integrator may rebind.
- `z` ranking runs on the UI thread per keystroke (2.7 ms in release at the 5 000 entry cap, see
  Measurements); move to a job if the cap is raised.
- Two running instances: last writer wins on frecency.toml (no cross-process merge).
