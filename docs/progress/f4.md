## Deviations (with reasons)
1. The spec mentions `[theme]` / `[syntax]` tables in `config.toml`. They do not exist: `Config` has
   `deny_unknown_fields`, `theme` is a name, and `[colors]` / `[syntax]` live in theme files. The README
   documents it that way and says so.
2. Manual-test draft corrections: at 80x24 the preview IS shown (it shows from 80 columns, hidden below);
   the size column is hidden by the list pane being under 60 columns, not by the terminal; find-file marks
   with `tab` (not `space`); `ctrl-o` is the dependable open key; `ks --debug-panic` is hidden but exists;
   Kestrel logs no "first frame" line (only `starting` and `image protocol ... took_ms=`), so the 60 ms
   check is by eye / `Measure-Command ks --version`; hook payloads are not logged (the `◆` marker, the
   tool name in the pane border and the changes view are the evidence); the WT split always runs the
   literal `claude`, `[claude] binary` only affects the embedded pane / preflight, so the fake-binary test
   uses the embedded pane.
3. Windows 10 "1809 or newer" is my reading of ConPTY's requirement; it is not enforced or tested.
4. No Rust code changed apart from the two additive tests.
